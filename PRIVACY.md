# Privacy / プライバシー

## Official statement

> This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

## English

Y-TEC Browser Capsule is a local Windows desktop application. It contains no telemetry, analytics, advertising, cloud synchronization, account service, automatic updater, or background network client.

The app may open a browser's official settings page or a local PDF only when the user selects the corresponding command. Network behavior of the separately installed browser and operating system is outside this application's control.

The local settings file contains only:

- the user's chosen default backup directory; and
- the UI language choice.

It does not store recovery keys, passphrases, browser profile data, saved-password CSV values, credentials, or analytics identifiers.

## 日本語

Y-TEC Browser Capsuleはローカルで動作するWindowsデスクトップアプリです。テレメトリー、アクセス解析、広告、クラウド同期、アカウントサービス、自動更新、バックグラウンド通信機能を含みません。

利用者が該当ボタンを選んだ場合だけ、別途インストール済みブラウザーの公式設定画面またはローカルPDFを開きます。ブラウザーおよびOS自体の通信は、本アプリの制御対象外です。

ローカル設定ファイルへ保存するのは、利用者が選んだ既定バックアップ先と言語設定だけです。復元キー、パスフレーズ、ブラウザープロファイル、保存パスワードCSVの値、認証情報、解析用識別子は保存しません。
