# エラーコード

画面に表示されるコードは、利用者が秘密情報や完全なファイルパスを
伝えずに状況を共有するための識別子です。

| コード | 意味 | 主な対応 |
| --- | --- | --- |
| `YBC-PROC-001` | 対象ブラウザーが起動中 | アプリの終了支援を使うか、対象ブラウザーを完全に終了 |
| `YBC-CRYPTO-001` | 復元キー／旧パスフレーズ不一致、破損、改ざん | 対応する2ファイルと元ファイルを確認し、復元は中止 |
| `YBC-CRYPTO-003` | その他のバックアップ読取失敗 | 元ファイルと保存先を確認 |
| `YBC-BACK-001` | バックアップ計画を作成できない | 選択内容とプロファイル状態を確認 |
| `YBC-REST-001` | 安全でない復元パスを検出 | バックアップを使用せず、配布元を確認 |
| `YBC-REST-002` | 復元先または復元計画が不正 | 対応付けと選択内容を確認 |
| `YBC-REST-003` | 復元に失敗し、自動ロールバック済み | 元状態を確認し、ロールバックを保持 |
| `YBC-REST-004` | 復元とロールバックの両方に失敗 | ブラウザーを起動せず、対象を変更しない |
| `YBC-CSV-002` | 保存パスワードCSVの形式または処理に失敗 | 公式画面から再エクスポート |
| `YBC-IO-001` | 保存先の空き容量不足 | 空き容量を確保するか保存先を変更 |
| `YBC-IO-002` | ファイルまたはフォルダーへのアクセス拒否 | 権限、読み取り専用、他アプリの使用を確認 |
| `YBC-IO-003` | その他のファイル入出力失敗 | 保存先、接続、ファイル使用状況を確認 |
| `YBC-UNEXPECTED-001` | 想定外の処理失敗 | 再試行し、再現時はコードと操作だけを報告 |

例外本文、復元キー、パスフレーズ、CSVの値、閲覧URL、ユーザー名、完全な
プロファイルパスは画面へ表示しません。平文CSVを削除できなかった場合だけ、
利用者が手動削除できるよう対象パスを明示します。
