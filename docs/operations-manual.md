# Y-TEC Browser Capsule 操作マニュアル

対象: `1.2.1`、Windows 10 / 11 x64

実画面付きPDF:
- 日本語: `output/pdf/Y-TEC_Browser_Capsule_操作マニュアル_1.2.1.pdf`
- English: `output/pdf/Y-TEC_Browser_Capsule_User_Manual_1.2.1.pdf`

## はじめに

Chrome、Microsoft Edge、Firefox / Firefox ESRのプロファイルを暗号化し、
同じPCまたは別PCへ移すポータブルアプリです。インストール、管理者権限、
ネットワーク接続は不要です。

保存パスワードはブラウザー内部から読みません。ブラウザー公式のCSV
エクスポート／インポートと本人確認を使います。

## 起動

1. 配布ZIPをローカルの空フォルダーへすべて展開します。
2. `YtecBrowserCapsule.exe`を起動します。
3. 配布元、Authenticode署名、公開SHA-256を確認します。Y-TEC自己署名は商用CAの信頼済み証明書ではなく、SmartScreen警告が表示される場合があります。

「操作マニュアル」から同梱PDF、「このアプリについて」から版数・
安全境界・Apache License 2.0を確認できます。

## 言語

「設定」で「システム既定」「日本語」「English」から選び、アプリを
再起動すると反映されます。言語変更前の既定バックアップ先は維持されます。
マニュアルボタンは現在のUI言語に対応するPDFを開きます。

## バックアップ

1. 対象プロファイルへチェックを付け、「バックアップを作成」を押します。
2. `.bvb`の保存先を選びます。
3. 保存内容を選び、「復元キーも必ず保管する」を確認します。
4. `.ybckey`の保存先を選びます。同じフォルダーの場合は警告を確認します。
5. 実行中ブラウザーがある場合は、未保存の入力を保存して終了支援を承認します。
6. 通常終了後も残る場合だけ、対象プロセスの強制終了を承認するか選びます。
7. 完了表示で`.bvb`と`.ybckey`の両方を確認します。

別PCへは両ファイルをコピーします。`.ybckey`はバックアップを開く秘密です。
紛失すると復元できません。盗難対策を高める場合は別のUSBメモリ等へ保管
してください。

### 保存パスワードも含める

1. 保存内容で「保存パスワードCSV」を選びます。
2. プロファイル名を確認し、「標準画面を開いて待機」を押します。
3. ブラウザー公式画面で本人確認し、表示された専用フォルダーへCSVを保存します。
   保存パスワードがないプロファイルは、待機中でも
   「このプロファイルはスキップ」を押して次へ進めます。
4. アプリが自動検出し、形式と書き込み完了を確認して直ちに一時暗号化します。
5. 「次へ」でプロファイルごとに繰り返します。

アプリが見るのは必須ヘッダーと件数だけです。値は画面やログへ出しません。
平文CSV削除失敗の警告が出た場合だけ、表示されたファイルを手動削除します。

## 完全検証

1. 「バックアップを検証」を押し、`.bvb`を選びます。
2. 対応する`.ybckey`を選びます。
3. 暗号タグ、全ファイルSHA-256、マニフェストの完了表示を待ちます。

旧1.0.0以前のBVB v1を選んだ場合だけ、従来パスフレーズ入力が表示されます。

## 復元

1. 「バックアップから復元」を押し、`.bvb`と`.ybckey`を選びます。
2. バックアップ元ごとに、同じブラウザーの復元先を明示選択します。
3. 別PC・別Windowsユーザーでは「別環境移行」を使います。
4. 復元内容を選び、実行中ブラウザーの終了支援を確認します。
5. アプリが現在状態の暗号化ロールバックを作成してから復元します。
6. ブラウザーを起動し、ブックマークや設定を確認します。

ロールバックにも`.bvb`と`.ybckey`があります。確認が終わるまで両方を
削除しないでください。Cookie、セッション、パスキーは別PCで使えない場合が
あります。

### 保存パスワードCSVを公式画面から戻す

1. 復元対応付けで「保存パスワードCSV（公式取込）」を選びます。
2. 対象ブラウザーとプロファイルを確認します。
3. 「公式インポート画面を開く」と「CSVの場所を開く」を使います。
4. 必要なら「フォルダーパスをコピー」を使います。CSVファイル名はコピーしません。
5. 公式画面でCSVを選び、本人確認と取込を完了します。
6. アプリへ戻り「インポート完了・削除」を押します。

アプリはブラウザーの認証情報データベースへ直接書き込みません。

## 複数Windowsユーザー

「読み取り可能なほかのWindowsユーザーも表示」は既定OFFです。現在の権限で
読めるプロファイル本体だけを追加できます。管理者権限やACL変更はしません。
保存パスワードCSVは対象ユーザーでサインインして公式画面を操作してください。

## 主な失敗時の確認

- ブラウザー終了: 未保存入力を保存し、通常終了→必要時だけ強制終了を使います。
- 復元キー不一致: 同じ日時・名前の`.bvb`と`.ybckey`か確認します。
- 復元キー紛失: アプリにも解除用バックドアはなく、復元できません。
- ロールバック失敗: ブラウザーを起動せず、ロールバック2ファイルと対象
  プロファイルを変更しないでください。
- CSV削除失敗: 警告された一時CSVを手動削除します。

## 対応外

- Windows 7 / 8 / 8.1、32-bit Windows
- スマートフォン、macOS、Linux
- Chrome / Edge Stable以外
- 保存パスワードの直接復号、DPAPI / App-Bound Encryption回避
- 認証情報データベース解析、本人確認の自動承認
- クラウド保存、自動更新、スケジュール実行
