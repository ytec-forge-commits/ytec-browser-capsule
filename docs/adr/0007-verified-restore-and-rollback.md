# ADR-0007: 選択展開、原子的置換、暗号化ロールバック

- 状態: 採用
- 日付: 2026-07-24
- 対象: Phase 5

## 判断

- 復元元と復元先は同じブラウザー内でユーザーが1対1に明示対応付けする。
- 検証済みマニフェストに実在するコンポーネントだけを復元画面で有効化し、存在しない項目の誤選択を防ぐ。
- 環境ID不一致は別環境移行を既定とする。同一環境扱いは二段階で明示承認する。
- プロファイルへ書き込む前に、復元先全体の暗号化ロールバックを作成・完全検証する。
- 元`.bvb`全体を認証しつつ、選択コンポーネントだけを復元ステージングへ書き出す。
- 復元先と同じボリュームで隣接一時ファイルを作り、長さとSHA-256を検証・flush後に原子的に置換する。
- 途中失敗またはキャンセルではロールバックを適用し、失敗した復元が新規作成したファイルも削除する。
- 保存パスワードCSVはこの経路へ含めず、別の公式インポート補助だけで扱う。

## 理由

一部だけ検証した復元、別ブラウザーへの割当、ブラウザー起動中の上書き、復旧不能な部分適用を防ぐ必要があります。ロールバック自身も同じ暗号形式で検証することで、平文退避を作りません。

## 結果

復元前にはバックアップと同程度の空き容量と時間が必要です。フル復元は安全なオーバーレイであり、バックアップに存在しない既存ファイルは削除しません。
