# ADR-0005: 固定計画によるプロファイルバックアップ

- 状態: 採用
- 日付: 2026-07-24
- 対象: Phase 3

## 判断

- ブラウザーごとのJSON規則でコンポーネント許可リストと除外を定義する。
- フルプロファイルでもキャッシュ、ロック、一時ファイル、保護対象の認証情報データベース名、リパースポイントを除外する。
- 書込前にファイルのパス、長さ、更新日時、コンポーネントを固定する。
- ブラウザーの既知実行ファイルが動作中なら開始せず、計画後にも再確認する。
- ファイル内容を平文アーカイブへ集約せず、暗号コンテナへ直接ストリーミングする。
- 進捗通知は約10回／秒へ抑える。

## 理由

ブラウザー起動中や計画後の変化を黙って取り込むと、整合しないバックアップを正常と誤認します。固定計画と再確認により、失敗を明示し、完成ファイルを検証済み状態だけに限定できます。

## 結果

一部の頻繁に変化する任意ファイルは警告付きで除外され得ます。フルプロファイルはブラウザー領域の完全複製ではなく、安全規則を適用したオーバーレイ用バックアップです。
