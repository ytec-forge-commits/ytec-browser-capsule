# ADR 0008: 利用者設定はLocalAppDataへ秘密なしで保存する

- 状態: 採用
- 日付: 2026-07-24

## 背景

ポータブル配布でも、利用者が毎回同じバックアップ先を探さずに
済む設定が必要です。一方、実行フォルダーはProgram Files、
読み取り専用媒体、共有フォルダーに置かれる可能性があり、
実行ファイル隣接への書き込みは安定しません。

## 決定

- 設定は現在ユーザーの
  `%LOCALAPPDATA%\Y-TEC\BrowserCapsule\settings.json`へ保存する。
- 現時点で保存する値は既定バックアップ先だけとする。
- パスフレーズ、認証情報、ブラウザーデータ、SID、PC名を
  設定へ保存しない。
- ネットワークパス、デバイスパス、相対パスを拒否する。
- `.partial`へ書いた後に設定ファイルを置換する。
- 完全検証、キャッシュ除外、CSV一時領域清掃、フルパス非表示は
  安全性に直結するため、画面で状態を示すが無効化させない。

## 結果

実行場所へ書き込み権限がなくても設定を保持できます。
設定ファイルには選択したローカルフォルダーのフルパスが平文で
含まれるため、現在ユーザーのLocalAppData内だけで扱い、ログや
診断情報へ転記しません。
