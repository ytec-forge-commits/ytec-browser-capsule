# ADR-0002: 正式名称とUI方針

- 状態: 採用
- 日付: 2026-07-24

## 文脈

本アプリは`ytec-diagnostic-tool`への収録に加え、WordPressから一般向けにも配布します。社内用だけに見える名称や画面、専門用語中心の操作では、バックアップ操作に不慣れな利用者が迷う可能性があります。

## 判断

- 正式表示名を**Y-TEC Browser Capsule**とする。
- コード、名前空間、プロジェクト識別子は`Ytec.BrowserCapsule`を使用する。
- 実行ファイル名は`YtecBrowserCapsule.exe`とする。
- Windows 10 / 11 x64専用とし、スマートフォン、Web、macOS、Linux版は作らない。
- UIは、操作に不慣れな人が「バックアップ」「引っ越し」「確認」の違いを直感的に理解できる日本語を優先する。
- 一画面に主目的を詰め込みすぎず、進行状況と次に行う操作を常に1つ明示する。
- 白から淡い寒色を基調に、丸みと小さなアクセント色を使う。過度な装飾や、灰色中心の業務システム風デザインは避ける。
- 警告、削除、復元は色だけに依存せず、文言とアイコン相当の形でも区別する。

## 影響

- 診断ツール内では`Y-TEC Browser Capsule`として表示する。
- WordPress公開ページでは「Chrome・Edge・Firefoxのバックアップ／引っ越しツール」を副題として併記する。
- 旧仮称をアセンブリ、EXE、公開文書、CI成果物へ残さない。
- Phase 1以降の画面レビューでは、機能の正しさに加えて、専門知識なしで次の操作が理解できるかを確認する。
