# ADR-0006: 保存パスワードは公式CSV方式だけを扱う

- 状態: 採用
- 日付: 2026-07-24
- 対象: Phase 4

## 判断

- 認証情報データベース、DPAPI、App-Bound Encryption、Firefox鍵DBを扱わない。
- ブラウザーとプロファイルを明示した公式パスワード管理画面だけを起動する。
- CSVは現在ユーザーとSYSTEMだけのACL一時領域へ保存させる。
- UTF-8と必須ヘッダーをストリーミング検証し、値を保持・表示・ログ出力しない。
- 検証直後にランダムなメモリ内一時鍵でAES-GCM暗号化し、平文削除を試みる。
- バックアップには元ファイル名を保存せず、プロファイルごとの固定パスへ格納する。
- 復元時も公式インポートUIを使い、プロファイルへ直接書き込まない。

## 理由

ブラウザーの保護機構を回避する実装は、安全性、将来互換性、配布時の信頼を損ないます。公式UIで本人確認を維持しつつ、平文CSVが存在する時間とアクセス権を最小化します。

## 結果

CSVエクスポート／インポートはユーザー操作が必要です。SSD上の削除済み平文を物理的に消去する保証はなく、削除失敗時は明示警告します。
