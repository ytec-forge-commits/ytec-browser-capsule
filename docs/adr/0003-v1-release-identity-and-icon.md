# ADR-0003: 1.0リリース識別情報とアプリアイコン

- 状態: 採用
- 日付: 2026-07-26

## 文脈

`0.9.0`受け入れ候補で機能・安全性・専用VM受け入れが完了したため、
WordPress一般配布と`ytec-diagnostic-tool`収録で共通して使う製品識別を
固定する必要があります。

## 判断

- 正式名称を**Y-TEC Browser Capsule**とする。
- 初回一般配布へ向けた正式バージョンを`1.0.0`とする。
- アセンブリバージョンとファイルバージョンを`1.0.0.0`とする。
- 実行ファイル名、名前空間、バックアップ拡張子は変更しない。
- アイコンは「3つのブラウザープロファイルを1つのカプセルへまとめる」
  意匠とし、外部ブラウザーの商標、鍵、南京錠、パスワード記号は使わない。
- 濃紺、青、白を基調に、3つのプロファイルをミント、アンバー、
  淡い青で区別する。
- Windowsの16pxから256pxまでを含むICOをアプリへ埋め込み、
  1024pxの透過PNGを公開用の正本とする。
- 一般配布は従来どおり未署名とし、ZIPと展開ファイルのSHA-256を
  改ざん確認の正本とする。

## 影響

- `0.9.0`のBVB v1バックアップは`1.0.0`でも読み取れる。暗号化形式、
  保存対象、復元方式、セキュリティ境界は変更しない。
- 既存の`0.9.0`専用VM証拠は履歴として保持し、`1.0.0`配布予定ZIPの
  検証結果とは混同しない。
- WordPress公開ページ、診断ツール、ZIP名では同じ名称と版を使用する。
